# Building Pragmatic AI: 10 AI Features Your Users Actually Want
Talk by Jonathan "J." Tower

Most AI conversations start with the technology: "we should add a chatbot," "we need an LLM strategy." This session starts from the other end, with a hiker who drove two hours to a trailhead and found out at mile two that the footbridge was gone. The app she planned the trip with knew. The answer was sitting in one sentence of one trip report she never read.

From there we'll walk through ten AI features your users actually want, each one starting from a real user problem: summarization, extraction, sentiment, semantic search, retrieval-augmented generation (RAG), recommendations, classification and routing, anomaly detection, human-in-the-loop approval, and agentic workflows. You'll see the problem, the idea, and how each one works. Four of them we'll build and run live in C# with Microsoft.Extensions.AI, mixing free local models on Ollama with gpt-4.1 and gpt-5.5 on Microsoft Foundry.

You'll leave with a better question than "Where can we use AI?", and a practical sense of which of these features are a few days of work, which ones need a human in the loop, and when a small local model is all you need.

Want to build all ten yourself? The full-day, hands-on workshop version of this talk, with labs in .NET, Python, and TypeScript, is at https://github.com/trailheadtechnology/10-ai-features-workshop.
